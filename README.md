# Libra — Library Management System

## Project description
Libra is a simple Library Management System built with HTML, CSS, and JavaScript. It helps manage books and track borrowing and returning.

## Features
- Dashboard with book and copy statistics
- Add, edit, delete, search, and filter books
- Track book categories
- Store borrower details
- Issue books and record due dates
- Return books and update availability
- Save demo data in the browser using `localStorage`

## Technologies used
- HTML
- CSS
- JavaScript
- Browser `localStorage`

## How to run
1. Download or clone this repository.
2. Keep `index.html`, `style.css`, and `script.js` in the same folder.
3. Open `index.html` in a web browser.

## Important note
This is a front-end demo. Data is stored only in the current browser on the current device. It does not sync between users or devices and is not a shared online database.

## Files
- `index.html` — page structure
- `style.css` — design and responsive layout
- `script.js` — book, borrower, issue, return, and local storage logic
- `README.md` — project documentation
